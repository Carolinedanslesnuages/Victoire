## Design Elements

### Text Overlay Template

**Title**:
- Font: System Bold (San Francisco for iOS, Roboto for Android)
- Size: 64pt
- Color: White with subtle shadow
- Position: Top 20% or Bottom 20%

**Subtitle**:
- Font: System Regular/Medium
- Size: 32pt
- Color: White with subtle shadow
- Position: Below title (16pt margin)

**Background**:
- Semi-transparent gradient overlay
- Dark gradient from bottom (40% opacity)
- Helps text readability

### Color Scheme
- Background Tint: Use PACE brand colors (subtle)
- Text: White (primary), Brand color (accents)
- Overlay: Dark gradient for text background

## Production Workflow

### Phase 1: Raw Capture (Day 1)
1. Set up app with demo data
2. Launch appropriate simulator/emulator
3. Navigate to each planned screen
4. Capture raw screenshots (Cmd+S or emulator button)
5. Organize in `source/raw-screenshots/` folder
6. Review for quality (no blur, proper layout)

### Phase 2: Design & Text (Days 2-3)
1. Open Figma/Photoshop template
2. Import raw screenshots
3. Add text overlays (title + subtitle)
4. Apply branding elements
5. Add subtle effects (shadows, gradients)
6. Create both French and English versions

### Phase 3: Export (Day 4)
1. Export each screenshot at exact required size
2. Optimize file size (PNG, <8MB each)
3. Name according to convention
4. Organize in appropriate folders
5. Verify dimensions and quality

### Phase 4: Review (Day 5)
1. Review all screenshots for consistency
2. Check text for typos
3. Verify proper localization
4. Get stakeholder approval
5. Make any final adjustments
